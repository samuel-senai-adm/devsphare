Projeto IoT • RFID • Automação

O futuro dos armários inteligentes já começou.

O SmartLocker é uma plataforma inteligente de gerenciamento de armários automatizados utilizando RFID, QR Code e IoT para oferecer segurança, praticidade e controle em tempo real.

Sobre o Projeto

Objetivo

Modernizar o gerenciamento de armários compartilhados através de uma plataforma inteligente e automatizada.

Tecnologia

Integração entre sistema web, RFID, QR Code e automação IoT utilizando ESP32.

Segurança

Controle digital de acessos, autenticação inteligente e monitoramento em tempo real.

Como Funciona

01

Reserva

O usuário realiza a reserva do armário diretamente pelo sistema.

02

Autenticação

O sistema valida o acesso utilizando QR Code ou RFID.

03

Abertura

O armário é liberado automaticamente apenas para o usuário autorizado.

Benefícios

Agilidade
